## Serein Chat v1.60

### 新增
- **高级参数真正可用**：设置 → 高级参数，可调「采样温度」（0–2.0 滑杆）与「单步最大输出」（默认 / 512 / 1024 / 2048 / 4096）。
  开启思考或联网时由服务端接管，面板显示锁定提示并把控件置灰。
- **首字延迟**：用量条新增 `首字 0.8s`，按轮记录。
- **自动发版**：推送 `v*` 标签即在 GitHub Actions（windows-latest）上构建并附加到 Release。
- **归档导入防护**：条目 ≤ 20000、单条 ≤ 64MB、解压合计 ≤ 256MB，超限直接拒绝。
