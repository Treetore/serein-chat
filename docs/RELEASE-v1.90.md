## Serein Chat v1.90

### 新增：本地性能统计面板
设置 → 性能统计，汇总近 50 次请求在**本机**的：

- 平均 / 最快 / 最慢 **首字延迟**
- 平均 **生成速度**（tok/s）
- 平均 **总耗时**
- 一键清空

明确标注：仅统计并保存在本机，不含任何对话内容，也不会外传。

`usage_log` 新增 `ms`、`ft_ms` 两列（DB 版本 2 → 3，自动迁移），逐轮记录总耗时与首字延迟。

### 修复
- 汇总只统计有效行：旧记录 `ms/ft_ms` 为 0 会把平均值拉低（曾出现「平均首字 75ms 但最快 610ms」的矛盾），现在平均值与最快/最慢自洽
- 平均耗时分母改为有效行数（此前得到 215ms 的错值）
- 服务商列表里 Responses 协议此前显示成 "OpenAI"，现正确显示 "Responses"

```
性能统计 / 近 18 次请求
平均首字 677ms   最快 610ms · 最慢 745ms
平均速度 120 tok/s
平均耗时 1.9s
```
